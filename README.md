# 🎪 学園祭レジ（Gakusai POS）

高校・大学の学園祭（模擬店）向けの、**インストール不要・オフラインで動く** シンプルなレジ（POS）システムです。
`index.html` をブラウザで開くだけで動作します。サーバーもアカウントも不要です。

## ✨ 特長

- **単一HTMLファイル** — `index.html` を開くだけ。インストール・ビルド・サーバー不要
- **オフライン対応** — ネットがなくても動作。データは端末内（localStorage）に保存
- **スマホ・タブレット対応** — 画面幅に応じてレイアウトが自動で切り替わるレスポンシブ設計
- **依存ライブラリなし** — 素の HTML / CSS / JavaScript のみ

## 📱 画面構成（下部タブ）

| タブ | 内容 |
|------|------|
| 🧾 レジ | 商品をタッチしてカゴに追加、合計・お預かり・おつりを自動計算して会計 |
| ⚙️ 設定 | 釣銭準備金（初期お釣り）の登録と、商品（名前・価格・初期在庫）の登録／編集／削除 |
| 📊 売上 | 総売上・会計件数・客単価、商品別ランキング、時間帯別グラフ（今日／締め後／全期間で切替） |
| 🕑 履歴 | 過去の会計を一覧・取り消し（取消時は在庫を自動復元） |
| 🔒 締め | 時間ごと／交代時に「釣銭準備金＋売上」と実際の現金を照合し、過不足を記録・履歴化 |

### 主な機能

- **レジ会計** — タッチ操作で商品を追加、数量調整、合計・おつりを自動計算
- **在庫カウント** — 販売数に応じて在庫を自動減算、売り切れ表示（在庫を空欄にすれば無制限）
- **釣銭準備金** — 開店時にレジへ入れた初期お釣り額を登録し、締めの照合に反映
- **売上集計** — 商品別ランキング・時間帯別グラフで売れ筋とピークを把握
- **会計履歴・取消** — 誤操作の会計を取り消すと在庫も元に戻る
- **締め・レジ点検** — 現金を数えて想定額（準備金＋売上）と照合、過不足を残す

## 🚀 使い方

1. `index.html` をダウンロード
2. 当日使う端末（スマホ／タブレット／PC）のブラウザで開く
3. **「設定」タブ**で釣銭準備金と商品を登録
4. **「レジ」タブ**で会計を開始

### 画面レイアウト

- **スマホ** — 縦1列（商品グリッド → カート → 会計ボタン）
- **タブレット・横長画面** — 2カラム（左に商品、右にカートと会計ボタンを固定表示）

> **⚠️ 運用上の注意**
> - データは開いた端末・ブラウザ内（localStorage）に保存されます。**同じ端末・同じブラウザで使い続けてください。**
> - ブラウザの「履歴・サイトデータの削除」を行うとレジのデータも消えます。営業中は削除しないでください。
> - **複数端末の売上を自動合算する機能はありません**（オフライン優先設計）。レジを分ける場合は、端末ごとに集計し、締めで合算する運用になります。
> - 本番前に一度テスト入力して動作を確認し、当日終了後に売上を控えておくことを推奨します。

## 🛠 技術

- 依存ライブラリなしの素の HTML / CSS / JavaScript（単一ファイル）
- データ保存：ブラウザの `localStorage`
